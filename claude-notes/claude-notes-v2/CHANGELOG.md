# Changelog

All notable changes to this Launchpad will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-21

### Added

- Initial release of the generic Launchpad template
- Team setup skill for interactive team onboarding
- Work-on skill for cloning and working on external repos in isolated workspaces
- Map-dependencies skill for service dependency discovery
- Update-launchpad skill for syncing team copies with upstream
- CLAUDE.md with operating instructions and company-agnostic conventions
- Team config schema (`teams/*.yml`)
- Skill eval framework under skill-specific `evals/` folders
- `.claude/settings.json` with sensible default permissions
- GitHub Copilot custom instructions for automated PR review
